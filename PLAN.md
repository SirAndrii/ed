# План реалізації застосунку оцінювання продуктів

## Огляд

Вебзастосунок для оцінювання продуктів за рівнем складності (тривоги).
Статичний сайт без серверу, дані в localStorage, публікація на GitHub Pages.

**Стек:** React + TypeScript + Vite + CSS Modules + Vitest

## Фаза 2 — Storage layer

### 2.1 `src/features/storage/`

- `storageService.ts` — CRUD для localStorage
  - `loadAppStorage()` — try/catch, валідація, defaults
  - `saveAppStorage(data)` — автозбереження
  - `resetAppStorage()` — з підтвердженням
  - `exportAppStorage()` — JSON download
  - `importAppStorage(file)` — завантаження з файлу
  - `exportCategory(categoryId)` — експорт однієї категорії
  - `resetCategory(categoryId)` — очищення однієї категорії
- Ключ: `"food-assessment-v1"` (без імені)
- Підтримка міграцій через schemaVersion

### 2.2 `src/hooks/useAppStorage.ts`

- React hook обгортка для storage
- Автозбереження при зміні стану

## Фаза 3 — Компоненти UI

### 3.1 Базові компоненти (`src/components/`)

- `AnimeGuide.tsx` — персонаж-помічник (маленька лисиця), CSS-анімація, respects prefers-reduced-motion
- `CategoryCard.tsx` — картка категорії (назва, опис, прогрес, статус, кнопка)
- `DifficultySelector.tsx` — 6 кнопок оцінки (low/medium/high/unsure/unfamiliar/skipped)
- `PastDifficultySelector.tsx` — 7 кнопок ретроспективної оцінки
- `FoodAssessmentCard.tsx` — картка одного продукту (назва uk/en, категорія, теги, оцінка)
- `FoodSearch.tsx` — пошук по каталогу
- `StoreTags.tsx` — відображення магазинних тегів
- `CategoryProgress.tsx` — індикатор прогресу (продукт N з M)
- `SessionComplete.tsx` — екран завершення категорії
- `BlockBreak.tsx` — екран перерви після блоку 8-10 продуктів
- `PrintReport.tsx` — компонент друку

### 3.2 Пошук (`src/features/search/`)

- `searchService.ts` — нормалізація, fuzzy match
  - Пошук по nameUk, nameEn, aliases, keywords
  - Case-insensitive
  - Trim пробілів
  - Частковий збіг
  - Сортування за релевантністю

## Фаза 4 — Сторінки (routing через HashRouter)

### 4.1 `src/pages/`

**WelcomePage.tsx** — `#/`
- Вітальне повідомлення (без оцінюючого тону)
- Кнопки: Обрати категорію, Продовжити (якщо є), Результати, Знайти продукт

**CategoriesPage.tsx** — `#/categories`
- Сітка карток усіх 19 категорій
- Статус кожної: не розпочато / у процесі / оцінено / частково / пропущено

**CategoryAssessmentPage.tsx** — `#/assess/:categoryId`
- Показ одного продукту за раз
- Прогрес: "Продукт 4 із 24"
- Блоки по 8-10 продуктів з перервами
- Навігація: Назад, Далі, Пропустити, Зберегти й вийти
- Автозбереження при виборі відповіді

**CategoryCompletePage.tsx** — `#/complete/:categoryId`
- Повідомлення про завершення
- Кнопки: Результати, Друк, До категорій, Завершити

**CategoryResultsPage.tsx** — `#/results/:categoryId`
- Статистика однієї категорії
- Фільтри по складності
- Зміна відповідей
- Друк/експорт однієї категорії

**AllResultsPage.tsx** — `#/results`
- Список категорій з їх статусами
- Без глобального відсотку
- Можливість відкрити результати окремої категорії

**SearchPage.tsx** — `#/search`
- Пошук по каталогу (uk, en, aliases, transliteration)
- Оцінка знайденого продукту окремо
- Додавання власного продукту якщо не знайдено

**SettingsPage.tsx** — `#/settings`
- Ім'я/псевдонім для звіту (необов'язково)
- Reduced motion toggle
- Показувати магазинні теги
- Експорт/імпорт даних
- Очищення даних (з підтвердженням)

## Фаза 5 — Стилізація

### 5.1 Дизайн-система

- М'які кольори, світлий фон
- Достатній контраст (WCAG AA)
- Великі touch targets (мінімум 44px)
- Округлі форми, м'які тіні
- Легке аніме-натхнення (не копіювати персонажів)

### 5.2 `src/styles/global.css`
- CSS custom properties для кольорів
- Responsive: мобілка → планшет → десктоп
- Focus states
- `prefers-reduced-motion` підтримка

- `@media print` — чорний на білому, без кнопок/навігації/персонажа

- Дата, назва категорії, легенда

## Фаза 7 — Тести (Vitest)

15 обов'язкових тестів:
1. Нормалізація пошуку
2. Пошук за альтернативною назвою
3. `гречка` знаходиться за `buckwheat`
4. `кисломолочний сир` знаходиться за `tvorog`
5. Збереження та відновлення localStorage
6. Обробка пошкодженого JSON
7. Додавання власного продукту
8. Незалежний прогрес категорій
9. Завершення лише «Фрукти»
10. Відсутність автопереходу до іншої категорії
11. Друк однієї категорії
12. Експорт однієї категорії
13. Порівняння оцінок зараз/рік тому
14. `unsure` не зараховується як `high`
15. Неоцінені = `unassessed`, не `skipped`
